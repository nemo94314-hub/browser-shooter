## 🚀 Запуск

1. Скачай все файлы в одну папку.
2. Открой `index.html` в браузере (Chrome, Firefox, Safari).
3. **Для мультиплеера** нужен локальный сервер (например, `python -m http.server` или Live Server в VS Code).

### Требования
- Браузер с поддержкой WebGL
- Интернет (для Three.js, Firebase, шрифтов)
- Для мультиплеера — Firebase-проект с Realtime Database

---

## 🛠️ Технологии

- **Three.js r128** — 3D-движок
- **EffectComposer** — пост-обработка (Film, Vignette)
- **Web Audio API** — процедурные звуки и музыка
- **Firebase Realtime Database** — мультиплеер
- **Canvas 2D** — фон меню
- **PWA** — установка на телефон как приложение

---

## 📊 Прогресс-система

Всё сохраняется в `localStorage` под ключом `zombieshoot_progress_v15`:
- Монеты
- Открытые уровни и звёзды (★☆☆ — ★★★)
- Купленные скины и оружие
- Уровни апгрейдов

Сбросить прогресс можно в **Настройках**.
